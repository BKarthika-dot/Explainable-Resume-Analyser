ROLE OVERVIEW
----------------------------------------------------------------
We are hiring an Associate AI/ML Engineer to bridge the gap between academic mathematical theory and robust production software systems. You will work side-by-side with senior machine learning architects to clean high-dimensional data, train tree-based and deep neural models, audit systems using explainable AI (XAI) primitives, and wrap solutions into real-time API frameworks.

An exceptional logical foundation, fluent Python coding, and a deep, self-driven technical curiosity are critical for success in this role.

----------------------------------------------------------------
KEY RESPONSIBILITIES
----------------------------------------------------------------

Model Development & Data Engineering
- Build, optimize, and evaluate supervised and unsupervised machine learning pipelines using Scikit-Learn, XGBoost, PyTorch, or TensorFlow.
- Design resilient data preprocessing steps, implementing custom feature extraction, transformations, scaling, and balancing methods.
- Apply structural model evaluation metrics beyond default accuracy (such as ROC-AUC, precision-recall curves, F1-score optimization).
- Implement explainable AI (XAI) tooling—explicitly extracting SHAP values, tracking feature importance matrix patterns, or deploying LIME models to interpret clinical or consumer predictions.

Production ML & Integration
- Wrap trained model assets into lightweight, sub-second latency microservice APIs using FastAPI, Flask, or modern asynchronous frameworks.
- Write clean, structured, and modular Python scripts conforming to strict Object-Oriented Programming (OOP) patterns.
- Manage custom codebase versions, handling secure branching, merges, and code documentation via Git and GitHub.
- Support real-time pipelines, including automated feature pipelines, speech-to-text transcripts analysis, or streaming micro-inferences.

Collaboration & Documentation
- Partner with data analysts and system engineers to map incoming relational database schemas into model input matrices.
- Document system architectures, hyperparameter selections, baseline benchmark evaluations, and feature metadata assets.
- Engage in collaborative peer reviews to ensure code production readiness and structural robustness.
