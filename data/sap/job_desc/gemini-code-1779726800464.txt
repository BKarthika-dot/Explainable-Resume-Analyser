----------------------------------------------------------------
KEY RESPONSIBILITIES
----------------------------------------------------------------

Model Development & DB Architecture
- Design, prototype, and optimize native SAP HANA database artifacts including Core Data Services (CDS) Views, AMDP (ABAP Managed Database Procedures), and complex stored procedures.
- Formulate high-performance transactional and analytical data structures to support high-throughput financial and logistical applications.
- Stay current with modern SAP release frameworks (S/4HANA programming models, clean core concepts) and implement state-of-the-art push-down techniques.
- Establish robust security frameworks utilizing analytical privileges at the database layer.
- Design custom data extraction structures to pipe massive transactional datasets from native HANA tables to external cloud platforms like Snowflake for high-tier corporate analytics.

Advanced ABAP Engineering & Production Lifecycle
- Develop, test, and deploy scalable custom solutions using Advanced Object-Oriented ABAP (OOPs), BAdIs, BAPIs, and the modern Enhancement Framework.
- Re-architect legacy procedural reports into modular, high-efficiency object classes.
- Own technical governance within the isolated **Sandbox Development environment** tier; aggressively isolate and stress-test custom functional modules, breaking mutations, and complex object classes in the Sandbox before committing packages to downstream development and QA transport tracks.
- Conduct continuous performance profiling and optimization using tools like ABAP Test Cockpit (ATC), SQL Trace (ST05), and Runtime Analysis (SE30) across all staging environments.
- Author reliable, automated interactive output layouts utilizing Adobe Forms frameworks.
- Write clean, secure, and transport-compliant Python or SQL scripts when interacting with hybrid database systems and external API frameworks.

Integration & UI5 Front-End (UX)
- Build and customize modern, cross-device, responsive web interfaces using SAPUI5 frameworks and JavaScript.
- Provision and optimize secure custom OData Services (V2/V4) via the SAP Gateway Service Builder (SEGW).
- Configure tile catalogs, target mappings, and authorization controls within the SAP Fiori Launchpad.
- Manage side-by-side or cloud-native extension architectures on SAP Business Technology Platform (BTP) using Cloud Foundry or SAP Business Application Studio to bypass modifying the core ERP.

Collaboration & Communication
- Work cross-functionally with product managers, data platform teams (Data Analysts/ML Engineers), database administrators, and business functional consultants (MM, SD, FICO) to translate functional requirements into high-fidelity technical specs.
- Translate complex system dependencies, transport sequences (STMS validation), and architectural risks into clear terms for non-technical stakeholders.
- Mentor junior developers; contribute to internal SAP technical documentation, coding standards, and transport release strategies.
